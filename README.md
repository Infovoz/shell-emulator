# Эмулятор командной строки UNIX (Вариант №18)

Приложение реализует эмулятор командной строки UNIX-подобной ОС с графическим интерфейсом на базе Tkinter. Все файловые операции производятся исключительно в памяти над виртуальной файловой системой (VFS), загружаемой из ZIP-архива.

## Функции и настройки

- **Интерфейс**: GUI с окном терминального вида. Заголовок формируется динамически: `Эмулятор [username@hostname]`.
- **VFS в памяти**: загружается из ZIP-архива. При отсутствии пути инициализируется стандартная файловая структура.
- **Логирование**: все действия и ошибки команд логируются в формате XML.
- **Стартовый скрипт**: поддерживается выполнение сценариев с пропуском ошибочных строк.
- **Поддерживаемые команды**:
  - `ls [путь]` — список файлов и директорий.
  - `cd [путь]` — смена текущей директории.
  - `cat <файл>` — вывод содержимого файла.
  - `tac <файл>` — вывод содержимого файла в обратном порядке строк.
  - `uname [-a]` — информация об операционной системе.
  - `cp <источник> <назначение>` — копирование файлов в памяти VFS.
  - `exit` — завершение работы программы.

### Параметры командной строки

- `--vfs <путь>` — путь к ZIP-архиву виртуальной файловой системы.
- `--log <путь>` — путь к файлу XML-журнала.
- `--script <путь>` — путь к файлу со стартовым сценарием.
